从家里的桌面照明开始

这个项目的起点很简单：想知道家里桌面、显示器附近和房间不同位置的照明情况。相比只凭眼睛判断，我希望有一个能随手打开、看读数、保存结果的工具，并且免费使用、没有订阅。

中文名称是知照 · 照度计，英文名称是 LightSense · Lux Meter。第一版先做 Android，因为设备如果配备环境光传感器，系统就能提供以 lux 为单位的读数，适合先把测量流程做好。

测的是照度，不是灯泡流明。lux 描述某个位置单位面积接收到的光；lumen（流明）描述光通量。这个 App 测量手机感光位置的照度，不能直接测出灯泡总共发出多少流明。

功能使用方式
实时照度显示当前 lux、时间加权均值、最低值和最高值，支持暂停、继续及统计清零。
稳定性判断观察最近约 3 秒的读数波动，帮助判断何时适合保存；稳定不等于准确。
参考照度计校准输入标准仪器参考值，预览比例系数并应用；也能恢复默认校准。
本地历史保存测量摘要、位置、备注以及当时的校准快照，可查看详情和删除记录。
多语言支持中文、英语、法语、德语和西班牙语，默认跟随系统，也能在设置中手动切换。
离线开源许可在“设置 → 开源许可”中阅读完整第三方许可文本。

测量引擎通过 Android 的 Sensor.TYPE_LIGHT 获取数据，不使用摄像头估算。硬件刷新频率、量程和传感器位置取决于手机；没有这类传感器的设备会显示不支持提示。

一次测量，按这几个步骤来

  1. 打开“测量”，找到手机的感光区域。它通常在顶部附近，具体位置以设备为准，避免用手、保护壳或物体遮挡。
  2. 把手机放到目标位置，尽量固定感光面的高度、方向和姿态。比较不同位置时，保持测量方式一致。
  3. 静置约 3 秒，观察读数及稳定提示。需要时清零统计，开始一轮新的比较。
  4. 点击“保存记录”，填写位置和可选备注。保存会暂停测量，下一轮点击“继续测量”。
  5. 有参考照度计时，让两者在尽可能相同的光照条件下测量，再输入参考值进行单点比例校准。

校准会重置当前统计并保持暂停。每条历史记录保留当时的校准信息，之后修改系数不会改写旧记录。

读数有用，但要知道边界

手机不是经过计量校准的专业照度计。不同传感器、光源光谱、入射角度、遮挡和测量姿态都会影响结果。单点校准只能修正一部分偏差，不能消除全量程误差或光谱差异。

我已经在实体 Android 手机上验证了照明变化时的读数响应，也验证了语言切换和离线许可页面；此前 16 项自动测试通过。这些验证证明功能能够运行，不代表已完成与专业仪器的精度认证。

它适合做家庭照明的初步观察和同一设备、相同姿态下的相对比较。涉及工程验收、职业照明评估等场景，应使用符合相应要求的专业仪器。

安装包通过 GitHub Release 附件分发。打开发布页，在 Assets 中选择 LightSense-0.2.1-release.apk，不要将自动生成的源码 ZIP 当成安装包。

  1. 在 Android 8.0 或更新系统的手机上下载安装包，且设备需要配备环境光传感器才能测量。
  2. 从下载来源打开 APK，按系统提示允许该来源安装应用，然后完成安装。
  3. 首次打开后观察实时读数；可短暂遮住感光区域再移开，检查读数是否响应。

数据留在本地，许可随包交付

当前版本不申请联网、相机或定位权限，没有账号登录、广告或订阅。测量摘要和校准档案保存在设备本地；清除应用数据或卸载会删除这些内容。

应用使用了 AndroidX、Kotlin 等第三方组件，完整许可和需要保留的版权声明已随安装包提供，可以离线阅读。使用这些组件不意味着本项目已经公开源码；目前源码仓库仍为私有。
